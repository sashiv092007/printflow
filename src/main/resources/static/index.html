Fair Priority-Based Print Job Management System

The problem

A shared printer receives normal and urgent documents. Urgent documents must be printed first, but normal users must still be served fairly, in the order they arrived.

      Scheduling rules
      
        
        
          
      • URGENT first
        • 
          
      • HIGH next
        • 
          
      • NORMAL last, first-in-first-out
        • 
          
      • Equal priority → earlier arrival wins
        • 
          
      • AGED a normal job passed over 3 times is promoted, so it is never starved
        • 
        
      
      
      

      
      
        
      Data structures used
      
        
      
          
      FIFO Queue linked nodes
      
          
      Fair print order for normal jobs: first submitted, first printed.
      
          
      Binary Max-Heap array-based
      
          
      Always exposes the most urgent job at the root; earlier arrival breaks ties.
      
          
      Hash Map separate chaining
      
          
      Maps each job ID to its job object for O(1) search, status and cancellation.
      
          
      Lazy deletion
      
          
      Cancel only flips the status in the hash map. The scheduler skips cancelled jobs when they
            reach the queue front or heap top, avoiding an O(n) removal.
